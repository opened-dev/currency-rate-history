# Currency Rate History

Одностраничный конвертер валют на React, Vite и TypeScript. Сумма и выбранная пара валют пересчитываются сразу, без сетевых запросов.

## Запуск

```bash
npm install
npm run dev
```

## Проверка

```bash
npm test
npm run build
```

В демонстрации используются фиксированные условные курсы к USD: USD = 1, EUR = 0.92, GBP = 0.79 и JPY = 150.
